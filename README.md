# Космическая стыковка

Шесть раундов логопедической игры на звук **С в начале слова**.

В каждом раунде появляется новый герой и четыре картинки. Карточки показываются по одной, затем ребёнок повторяет порядок. За правильный ответ загорается один из четырёх индикаторов. Ошибка сбрасывает ввод, а кнопка повтора показывает тот же шифр.

После четырёх правильных ответов трос подключается к гнезду, открывается люк, котёнок влетает в шлюз, трос подтягивается, люк закрывается. Все шесть героев моргают и покачиваются. После закрытия люка начинается следующий раунд; после шестого появляется общий финал.

## Запуск

Статический HTML/CSS/JavaScript, без сборки и внешних библиотек. Для локального запуска нужен HTTP-сервер:

```sh
node server.js
```

Открыть http://127.0.0.1:47821. На GitHub Pages достаточно публикации корня ветки. Относительные пути подходят для `/kosmos/` и iframe.

## Управление

Мышь, касание, клавиши 1–4, Tab/Enter/Space. Кнопки: повтор шифра, звук, меню и полный экран (если доступен в браузере/iframe). При возврате к вкладке демонстрация начинается заново. Предусмотрено сокращение движений по системной настройке.

## Раунды

Все шесть раундов включены. Игра использует каждую картинку ровно дважды, все 12 встречаются за первые три раунда.

| Герой | Картинки |
|---|---|
| Кот | Собака, сумка, сок, сапоги |
| Мишка | Соты, сова, салат (листья), самокат |
| Белка | Самолёт, санки, совок, сундук |
| Собака | Собака, соты, самолёт, сумка |
| Енот | Сова, сок, санки, салат |
| Волк | Сапоги, самокат, совок, сундук |

`assets/` — рабочая графика, три набора карточек и по два кадра каждого героя. `design/` — согласованные эскизы и сведения об исходниках.

Инструкция видна только в стартовом окне. На игровом поле нет заголовка, подписи о шифре и дополнительных рамок вокруг голубых карточек.

## Проверка

```sh
node --test tests/logic.test.js
```

Проверяются покрытие слов, неповторяющийся шифр, правильные/ошибочные ответы и порядок событий стыковки: подключение → открытие → вход → закрытие.

## Выбор положения звука
В стартовом меню доступны С в начале (12 слов), середине (9), конце (8), стечениях (8). Каждый набор содержит шесть раундов со всеми героями, по четыре картинки. Все слова выбранного набора встречаются за игру, внутри одного раунда повторов нет. Кнопка меню позволяет сменить набор; «Играть ещё» повторяет выбранный набор. Количество картинок и героев в меню не показывается.
