# Космическая стыковка

Пробный раунд логопедической игры на звук **С в начале слова**.

Сейчас работает один раунд с котёнком: собака, сумка, сок, сапоги. Карточки показываются по одной, затем ребёнок повторяет порядок. За правильный ответ загорается один из четырёх индикаторов. Ошибка сбрасывает ввод, а кнопка повтора показывает тот же шифр.

После четырёх правильных ответов трос подключается к гнезду, открывается люк, котёнок влетает в шлюз, трос подтягивается, люк закрывается. Котёнок моргает и покачивается; оба уха находятся внутри шлема.

## Запуск

Статический HTML/CSS/JavaScript, без сборки и внешних библиотек. Для локального запуска нужен HTTP-сервер:

```sh
node server.js
```

Открыть http://127.0.0.1:47821. На GitHub Pages достаточно публикации корня ветки. Относительные пути подходят для `/kosmos/` и iframe.

## Управление

Мышь, касание, клавиши 1–4, Tab/Enter/Space. Кнопки: повтор шифра, звук, меню и полный экран (если доступен в браузере/iframe). При возврате к вкладке демонстрация начинается заново. Предусмотрено сокращение движений по системной настройке.

## Следующий этап

Остальные пять раундов ещё не включены: сначала проверяется пробный раунд. Все шесть дизайнов героев согласованы, все 12 предметных иллюстраций подготовлены. План в `logic.js` использует каждую картинку ровно дважды, все 12 встречаются за первые три раунда.

| Герой | Картинки |
|---|---|
| Кот | Собака, сумка, сок, сапоги |
| Мишка | Соты, сова, салат (листья), самокат |
| Белка | Самолёт, санки, совок, сундук |
| Собака | Собака, соты, самолёт, сумка |
| Енот | Сова, сок, санки, салат |
| Волк | Сапоги, самокат, совок, сундук |

`assets/` — рабочая графика и три набора карточек; `design/` — согласованные изображения для последующей подготовки остальных героев к анимации. Персонажи в `design/` пока являются иллюстрациями, не готовыми анимационными слоями.

## Проверка

```sh
node --test tests/logic.test.js
```

Проверяются покрытие слов, неповторяющийся шифр, правильные/ошибочные ответы и порядок событий стыковки: подключение → открытие → вход → закрытие.
